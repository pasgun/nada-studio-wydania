# Nada Studio – wydania

Gotowe instalatory apki Nada Studio i paczki aktualizacji silnika. Apka pobiera je stąd sama.

- **Instalator Windows:** [najnowsze wydanie](https://github.com/pasgun/nada-studio-wydania/releases/latest) → plik `Nada-Studio-Setup-….exe`
- **Silnik:** wydanie „silnik” (pre-release) z `manifest.json` i paczką `silnik-<wersja>.zip`
