# Nada Studio – wydania

Gotowe instalatory apki Nada Studio i paczki aktualizacji silnika. Apka pobiera je stąd sama.

- **Instalator Windows:** folder [`apka/`](apka) → plik `Nada-Studio-Setup-….exe` (przycisk „Download raw file”)
- **Silnik:** folder [`silnik/`](silnik): `manifest.json` i paczka `silnik-<wersja>.zip`
